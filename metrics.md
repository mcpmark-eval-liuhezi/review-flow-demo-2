# Metrics Being Collected

- **request_count** - total number of incoming requests per sampling interval
- **request_latency_ms** - p50 / p95 / p99 response times
- **error_rate** - share of failed responses
- **active_sessions** - concurrently active user sessions
- **cpu_usage** - host CPU utilization percentage
- **memory_usage** - resident memory usage in MB

Data retention: 90 days
