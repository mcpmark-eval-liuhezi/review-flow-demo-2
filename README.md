# review-flow-demo-2

Disposable sandbox for a hands-on GitHub collaboration workshop - clean review-flow walkthrough (branch, PR, inline review comments, issue, gist).

This repository is fully disposable. Nothing here is real production content - it exists purely so the workshop can walk through the GitHub collaboration flow end to end without touching anything important.

## What we'll cover

- Branching off the default branch for feature work
- Opening a pull request with a clear title and description
- Leaving an inline review with threaded comments on the diff
- Filing a follow-up issue that references the pull request
- Pushing an extra commit so attendees see a PR grow after feedback
- Wrapping up with a summary gist
